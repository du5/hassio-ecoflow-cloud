# Power Kits 二代（智控五合一充逆一体机 5kVA）接入说明

本页按 EcoFlow 官方命名整理二代 Power Kits 的组成、规格、数据模块与 Home Assistant 设备的对应关系。
数据来源分三类：**实测** 指从一台二代主机的 App 协议报文（`latestQuotas` 回复与心跳）中读到的值；
**配电盘手册** 指 30/50A 交直流智能配电盘的官方中文用户手册；**规格表** 指零售商页面引用的主机规格，
官方中文主机手册待核对的条目已注明。

## 配电盘规格（EF-PK-005-2，配电盘手册）

- 交流：分相 L1 / L2 / N，输入最大 50 A、120/240 V、60 Hz；最多 12 个分支回路（6 个断路器位，双联断路器为两回路）；每分支最大 30 A。
- 直流：输入最大 100 A、13/26 V；输出 F1–F13 最大 30 A，F14–F16 最大 50 A；共 16 个可控回路。
- 远程控制：主交流输出、主直流输出和 16 个直流回路可在控制台或 App 上远程控制，交流分支回路不支持远程控制，只能拨动断路器。
- 固件随 Power Hub 的更新包一起更新。

## 数据模块与 Home Assistant 设备

App 协议把一套系统拆成若干模块上报，每个模块在 Home Assistant 里是一个设备。模块类型与一代 Power Kits 的公共 API 文档一致。

| 模块类型 | 所属组件 | 实测序列号前缀 | HA 设备 | 可控项 |
| --- | --- | --- | --- | --- |
| `wireless` / `gps` | 主机本体 | M3H1 | 主机设备（总电量、总功率、总电流、剩余时间、充放电上下限、发电机启停电量） | 无 |
| `iclow` | 主机 逆变充电 电池侧（BMS） | M1095-PSDL | 系统电量、母线电压、电池电流、温度、保护状态 | 无（命令由它执行，开关放在 `ichigh`） |
| `ichigh` | 主机 逆变充电 交流侧 | M1095-PSDH | 交流输出功率、电压、电流、频率、视在功率、市电输入、`appCfg` 当前设置 | 交流输出、交流充电、交流充电电流、市电优先 |
| `kitscc` | 主机 MPPT 太阳能充电控制器 | M1096-MPPT | 两路 PV 功率、电压、电流、温度 | 无 |
| `bbcin` | 主机 DC-DC 电池充电器（车充 / 发电机输入） | M3593-DCIN | 直流输入功率、电压、电流、限流、模式 | 无（主直流输出开关放在 `bbcout`） |
| `bbcout` | 主机 DC-DC 降压输出 | M3593-DCOU | 直流负载功率、电流、输出状态 | 主直流输出 |
| `bp5000` | 磷酸铁锂电池 5kWh，每块一个设备 | M101Z | 电量、电压、电流、温度、循环、健康度、累计充放电量 | 无 |
| `lddc` | 配电盘 直流回路 | M3L1 | 16 路功率、电流，温度，继电器位图 | 直流回路 F1–F12 开关；F13–F16 只读 |
| `ldac` | 配电盘 交流回路 | M3L1（与 `lddc` 同一序列号） | 6 个断路器位功率、电流，L1 / L2 总功率与电压 | 无（手册：交流分支不可远程控制） |

配电盘的交流板和直流板共用一个序列号，集成会把它们登记为 `序列号#ldac` 和 `序列号#lddc` 两个设备，设备页上的序列号仍显示真实序列号。

在线模块列表（`onLineModuleSnList`）里还有三个没有数据流的模块：M3593-BPRT（moduleDetail 14）、M35J3-EXRT（moduleDetail 19）、M106ZCB5ZJ3C0022（moduleType 60，moduleDetail 13）。
推测分别对应电池底座、Power Link 和显示屏中的某一个，待核对，目前不生成设备。

## 已知限制

- 所有开关和滑块沿用 EcoFlow 为一代 Power Kits 公开的命令格式，尚未在二代真机验证。
- 直流回路 F13–F16 的开关命令未知，先只读。
- 交流充电电流滑块的范围是 0–40 A，实际上限以 App 为准（本机当前设定 20 A）。
